## 📦 Instalação

<details>
<summary><b>🐧 Linux (Ubuntu/Debian)</b></summary>

```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv
python3 --version
```
</details>

<details>
<summary><b>🪟 Windows</b></summary>

1. Acesse [python.org/downloads](https://python.org/downloads)
2. Baixe o instalador
3. **Marque "Add Python to PATH"** durante a instalação
4. Abra o terminal (`cmd` ou `PowerShell`) e digite:
```bash
python --version
```
</details>

<details>
<summary><b>🍎 macOS</b></summary>

```bash
# Com Homebrew
brew install python3

# Ou baixe o instalador em python.org
```
</details>

<details>
<summary><b>🔬 Anaconda (recomendado para Data Science)</b></summary>

```bash
# Baixar Miniconda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh

# Criar e ativar ambiente
conda create -n meu_ambiente python=3.11
conda activate meu_ambiente
```
</details>

## 📘 Aprenda Python

### 🔹 Primeiros passos

```python
# Olá, mundo!
print("Hello, Python! 🐍")

# Variáveis e tipos
nome = "Python"
versao = 3.11
ativo = True
print(f"{nome} versão {versao}")

# Listas e loops
linguagens = ["Python", "JavaScript", "Go", "Rust"]
for lang in linguagens:
    if lang == "Python":
        print(f"{lang} é a melhor! 💚")
```

### 🔹 Gerenciamento de pacotes

```bash
# Instalar pacotes
pip install numpy pandas matplotlib

# Instalar a partir de requirements.txt
pip install -r requirements.txt

# Listar pacotes
pip list

# Atualizar pip
pip install --upgrade pip
```

### 🔹 Ambientes virtuais (boas práticas)

```bash
# Criar ambiente
python3 -m venv .venv

# Ativar
source .venv/bin/activate      # Linux/macOS
.venv\Scripts\activate          # Windows

# Instalar dependências do projeto
pip install -r requirements.txt

# Sair do ambiente
deactivate
```

### 🔹 Executando projetos

```bash
# Script direto
python script.py

# Modo interativo (REPL)
python

# Jupyter Notebook
jupyter notebook
# ou
jupyter lab

# Aplicação web
uvicorn main:app --reload       # FastAPI
flask run                       # Flask
streamlit run app.py            # Streamlit
```
